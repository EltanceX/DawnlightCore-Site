一个光影包是可寻址的资源集合。Manifest 是入口，Programs 描述着色器程序，Resources 描述纹理/缓冲区，Passes 描述执行关系，Settings UI 描述作者可暴露的参数。

```text
shaderpack.json       # 包入口
shaders/              # vertex / fragment / compute 文件
textures/             # 包内纹理资源
manifest/ui/           # 可选 Settings UI
```

路径是包内相对路径，不等价于宿主文件系统路径。Core 可以拒绝不安全路径、未知资源类型或无法解析的引用。

包模型和 [受信 Catalog 边界](/zh-CN/docs/preview/02-concepts/trusted-catalog-boundary) 分开理解：包可以描述引用，但 Catalog 和引擎 provider 是否存在由 Core 决定。
