显示文本和机器 id 分开维护。控件 id、option value 和 shader 参数名保持稳定，本地化文件只负责用户看到的标题、说明和枚举标签。

缺少翻译时应有可理解的 fallback，不要把内部 key 或空字符串当作最终文案。中文文案首次出现技术术语时保留英文 ID，例如“历史缓冲区（history resource）”。

新增语言不会改变 Manifest 合同版本，但可能暴露文本长度和布局问题；发布前应在移动宽度检查长标题和多行说明。
