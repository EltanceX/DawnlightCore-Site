Pass 是管线的执行单元。它通常关联一个 stage/template、一个 Program、输入输出资源和 commands。`drawbuffers` 指定颜色输出槽位；它不是任意纹理名列表，必须与当前 Pass 和资源声明相容。

```json
{
  "name": "composite",
  "program": "composite",
  "drawbuffers": ["colortex0"],
  "historyCommit": ["colortex0"]
}
```

命令类型、作用域和资源访问规则见 [Command types](/zh-CN/docs/preview/06-reference/command-types)。不要假定命令列表顺序可以越过 Core 固定的阶段边界；JSON 描述的是允许的工作，而不是替换引擎调度器。
