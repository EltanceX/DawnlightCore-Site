Program 是着色器入口和编译选项的逻辑注册。一个 Pass 通过 Program ID 使用它，而不是直接把文件路径写进每一条执行命令。

```json
{
  "programs": {
    "composite": {
      "vertex": "shaders/composite.vert",
      "fragment": "shaders/composite.frag"
    }
  }
}
```

文件路径必须是包内路径，Program ID 在其作用域内唯一。编译失败、阶段缺失或引用不存在的 define 时，应回到 Program 注册和对应的诊断输出排查。
