当前快照定义的 Catalog 诊断包括 `DuplicateRegistration`、`UnknownIdentifier` 和 `UnsupportedVersion`；Manifest 还可能产生 `OptionalServiceCatalogReferenceUnavailable` 警告。

报告诊断时至少保留 code、severity、文件路径、JSON pointer（如果工具提供）和 Core commit。不要只截图一段本地化文本，因为文本可能随版本变化。

Settings UI 的 authored 校验仍属于实验能力。`P9UI203` 等页面中出现的诊断码应与目标 Loader 输出对照，网站页面本身不执行 C# 验证。
